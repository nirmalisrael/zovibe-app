# Entity: `Playlist` (`/playlists`)

| Field | MockAPI type | Required | Description |
|-------|----------------|----------|-------------|
| `id` | Auto | yes | Generated by MockAPI |
| `userId` | String | yes | Owner’s `users.id` |
| `name` | String | yes | Playlist title |
| `description` | String | no | Can be empty string |
| `songIds` | String | yes | JSON **as text**, array of JioSaavn song id strings |
| `coverUrl` | String | no | URL or `""` |
| `createdAt` | String | yes | ISO-8601 datetime |

### Example JSON

```json
{
  "userId": "1",
  "name": "My mix",
  "description": "",
  "songIds": "[]",
  "coverUrl": "",
  "createdAt": "2026-03-29T12:00:00.000Z"
}
```

TypeScript: `src/entities/playlist.ts` (`PlaylistEntity`).
