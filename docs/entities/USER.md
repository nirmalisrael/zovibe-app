# Entity: `User` (`/users`)

| Field | MockAPI type | Required | Description |
|-------|----------------|----------|-------------|
| `id` | Auto | yes | Generated by MockAPI |
| `name` | String | yes* | Full display name, e.g. `Nirmal Israel` |
| `username` | String | yes | Login handle, unique, e.g. `nirmalisrael` (no spaces) |
| `email` | String | yes | e.g. `nirmal@nomail.com` |
| `password` | String | yes | App sends **base64** of password, not plain text |
| `avatar` | String | yes | Usually 2-letter initials from `name`, e.g. `NI` |
| `createdAt` | String | yes | ISO-8601 datetime |
| `likedSongs` | String | yes | JSON **as text**, e.g. `[]` or `["songId1"]` |
| `recentlyPlayed` | String | yes | Same; app keeps at most 20 ids |
| `playlists` | String | yes | JSON **as text**; app uses `[]`; rows live on `/playlists` |

\*Existing rows without `name`: app uses `username` as fallback label until you set `name`.

### Example JSON (POST body shape)

```json
{
  "name": "Nirmal Israel",
  "username": "nirmalisrael",
  "email": "nirmal@nomail.com",
  "password": "<base64>",
  "avatar": "NI",
  "createdAt": "2026-03-29T12:00:00.000Z",
  "likedSongs": "[]",
  "recentlyPlayed": "[]",
  "playlists": "[]"
}
```

Login uses **`username` + `password`** (filter: `GET .../users?username=nirmalisrael`).

TypeScript: `src/entities/user.ts` (`UserEntity`).
